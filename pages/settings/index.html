使用提示

  • 指令:/画图 <提示词> [-n 张数] [-a 宽高比] [-s 分辨率],别名 /绘图 /生图 /draw /img
  • 宽高比 -a 可选 1:1 / 16:9 / 9:16 / 4:3 / 3:4;分辨率 -s 可选 1K / 1.5K / 2K
  • 管理员豁免指 AstrBot 全局管理员;开启后不受冷却与限额限制,但仍计入「配额」页使用明细
  • 开启 LLM 润色后,完整润色结果可在控制台日志中查看
  • 方舟 2K 生成约需 1~3 分钟,请耐心等待,勿连续刷屏
  • 免费额度耗尽会出现 429 / SetLimitExceeded,需到火山方舟控制台关闭「安心体验模式」
