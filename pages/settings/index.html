使用提示

  • 使用 /画图 <提示词> [-a 宽高比] [-s 分辨率] 生成图片，也可使用别名 /draw
  • -a 支持 1:1、16:9、9:16、4:3、3:4、3:2、2:3、21:9；-s 支持 1K、1.5K、2K
  • 管理员豁免仅适用于 AstrBot 全局管理员；使用量仍会记录在用量页面
  • 启用 LLM 润色后，可在 AstrBot 日志中查看完整的润色结果
  • 高分辨率图片通常需要 1 至 3 分钟，请避免重复提交相同任务
  • 出现 429 或 SetLimitExceeded 时，请检查火山方舟额度、限流和安心体验模式设置
