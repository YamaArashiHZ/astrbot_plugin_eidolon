# Eidolon

Eidolon 是一款面向 AstrBot 的群聊文生图/图生图插件，使用火山方舟 Doubao Seedream 5.0 Pro 生成图片。

## 功能

- 支持 `/画图` 与 `/draw` 指令。
- 支持宽高比和分辨率参数。
- 支持图生图：附带图片或回复带图消息时，自动基于参考图片生成，支持单图编辑与多图融合。
- 可选群聊 `@机器人` 自然语言触发，支持自定义关键词或 LLM 意图判断。
- 支持可配置的全局并发队列，超出上限时即时反馈排队位置。
- 支持群冷却、每日总限额、个人每日限额和管理员豁免。
- 可调用 AstrBot 已配置的文本模型润色提示词，并支持独立设置润色超时。
- 支持限制本地图片缓存容量，超限后自动清理最旧图片，也可在管理页手动清空。
- 提供插件管理页面，用于配置服务、生成参数、缓存、用量限制和查看统计信息。

## 环境要求

- AstrBot `>=4.16,<5`
- `aiocqhttp` 平台
- 已开通火山方舟 Seedream 5.0 Pro，并拥有可用的 API Key

## 安装

通过 AstrBot 插件市场安装，或将本仓库放入 AstrBot 的插件目录后重载插件。

安装完成后，打开 Eidolon 的插件设置页面，填写以下必要信息：

- 火山方舟 API Key
- Seedream 模型 ID 或推理接入点 ID

建议先使用“测试连接”，再使用“测试生成”验证完整生成链路。测试生成会实际调用模型并产生费用。

## 使用方法

```text
/画图 一只坐在云朵上的橘猫
/画图 赛博朋克城市夜景 -a 16:9 -s 1.5K
/draw 水彩风格的山间湖泊 -a 4:3 -s 2K
```

可用参数：

| 参数 | 说明 | 可选值 |
| --- | --- | --- |
| `-a` | 宽高比 | `1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`、`21:9` |
| `-s` | 分辨率 | `1K`、`1.5K`、`2K` |

## 图生图

在提示词后附带一张或多张图片，或回复一条带图片的消息后再输入 `/画图`，插件会自动将图片作为参考图：

```text
/画图 把背景换成海边 [附带图片]
/画图 融合这几张照片生成一张合影 [附带多张图片]
/画图 把猫换成狗 [回复上一条带图消息]
```

- 支持单图编辑与多图融合，同一请求最多使用 8 张参考图。
- 图生图不进行 LLM 提示词润色，也不受润色配置影响。
- 图生图与文生图共用每日限额、群冷却与并发队列；可在管理页关闭图生图功能。
- 未显式指定 `-a` 时，输出构图默认参考输入图片，无需手动指定宽高比。

## 自然语言触发

开启后，群内 `@机器人` 并附带描述即可生图，无需使用指令。插件会先判断消息是否为生图请求：

- **自定义关键词**：消息命中任一配置的关键词即生图，其余消息放行给正常对话。
- **LLM 判断**：由独立配置的文本模型判断意图；非生图请求、模型未配置或判断失败时，均放行给正常对话。

LLM 判断模型独立于提示词润色模型，可在插件设置中分别选择。判断结果会写入 AstrBot 日志。

## 并发与排队

默认最多同时执行 5 个图片生成任务，可在插件设置中修改。达到并发上限后，新请求会按提交顺序进入队列，并立即收到排队位置提示。

火山方舟的模型限流独立于插件并发设置。出现 HTTP 429 时，请降低并发数，或检查账号的模型限流与额度。

## 数据目录

插件配置、用量记录和生成图片保存在：

```text
data/plugin_data/astrbot_plugin_eidolon/
```

其中：

- `config.json`：插件配置
- `usage.json`：今日及历史用量统计
- `images/`：生成图片缓存；达到配置的容量上限后自动删除最旧文件

缓存容量可在插件管理页面中调整，最低为 1 MB。手动清空缓存不会删除配置或用量记录，正在发送的图片不会被自动或手动清理。

## 注意事项

- 火山方舟返回的图片 URL 仅在有限时间内有效，Eidolon 会下载图片后再发送。
- 高分辨率图片通常需要 1 至 3 分钟生成。
- 请妥善保管 API Key，不要将包含真实密钥的配置文件提交到公开仓库。
- 使用本插件时应遵守 AstrBot、火山方舟及所在平台的服务条款和内容规范。
