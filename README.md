# Eidolon

Eidolon 是一款面向 AstrBot 的群聊文生图插件，使用火山方舟 Doubao Seedream 5.0 Pro 生成图片。

## 功能

- 支持 `/画图` 与 `/draw` 指令。
- 支持宽高比和分辨率参数。
- 可选群聊 `@机器人` 自然语言触发。
- 支持可配置的全局并发队列，超出上限时即时反馈排队位置。
- 支持群冷却、每日总限额、个人每日限额和管理员豁免。
- 可调用 AstrBot 已配置的文本模型润色提示词。
- 提供插件管理页面，用于配置服务、生成参数、用量限制和查看统计信息。

## 环境要求

- AstrBot `>=4.16,<5`
- `aiocqhttp` 平台
- 已开通火山方舟 Seedream 5.0 Pro，并拥有可用的 API Key

## 安装

通过 AstrBot 插件市场安装，或将本仓库放入 AstrBot 的插件目录后重载插件。

安装完成后，打开 Eidolon 的插件设置页面，填写以下必要信息：

- 火山方舟 API Key
- Seedream 模型 ID 或推理接入点 ID

建议先使用“测试连接”，再使用“测试生成”验证完整生成链路。测试生成会实际调用模型并产生费用。

## 使用方法

```text
/画图 一只坐在云朵上的橘猫
/画图 赛博朋克城市夜景 -a 16:9 -s 1.5K
/draw 水彩风格的山间湖泊 -a 4:3 -s 2K
```

可用参数：

| 参数 | 说明 | 可选值 |
| --- | --- | --- |
| `-a` | 宽高比 | `1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`、`21:9` |
| `-s` | 分辨率 | `1K`、`1.5K`、`2K` |

## 并发与排队

默认最多同时执行 5 个图片生成任务，可在插件设置中修改。达到并发上限后，新请求会按提交顺序进入队列，并立即收到排队位置提示。

火山方舟的模型限流独立于插件并发设置。出现 HTTP 429 时，请降低并发数，或检查账号的模型限流与额度。

## 数据目录

插件配置、用量记录和生成图片保存在：

```text
data/plugin_data/astrbot_plugin_eidolon/
```

其中：

- `config.json`：插件配置
- `usage.json`：今日及历史用量统计

## 注意事项

- 火山方舟返回的图片 URL 仅在有限时间内有效，Eidolon 会下载图片后再发送。
- 高分辨率图片通常需要 1 至 3 分钟生成。
- 请妥善保管 API Key，不要将包含真实密钥的配置文件提交到公开仓库。
- 使用本插件时应遵守 AstrBot、火山方舟及所在平台的服务条款和内容规范。
